# Sales Margin & Discount Optimization Analysis

## Project Overview
An end-to-end data analytics project analyzing 9,994+ retail and B2B order records to uncover revenue leaks, margin erosion, discount impact, and high-value customer segments.

## Tools Used
- **SQL (MySQL / PostgreSQL):** Aggregations, CTEs, discount-tier segmentation, and customer profitability analysis.
- **Excel:** Data cleaning, validation,
